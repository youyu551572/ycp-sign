# 授权签发页

一个**单文件**的授权码签发工具，手机浏览器打开就能用。

## 这是什么

给 Youyuzcodepool 签发授权码的页面。纯静态、无后端、可离线。

## 怎么用

访问：**https://youyu551572.github.io/ycp-sign/**

然后按页面提示：输口令 → 填信息 → 生成授权码。

## 安全说明

**页面本身不含任何敏感信息** —— 私钥在你的书签 URL 里（加密后），
不在这个页面里。所以把这个页面公开托管是安全的。

口令只在你手机本地用来解密私钥，**不会发送到任何地方**（页面不联网）。
